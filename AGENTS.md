# AGENTS.md

Humans and AI agents (Claude Code, Codex, and others) follow the same rules here. Read README.md before editing.

## Commit messages

- Write every commit with a subject and a body. The subject says what changed. The body states what changed, why it changed (the request, issue, or finding it answers), and what was checked (the tests and commands run and their results, and what was not checked). Do not leave subject-only commits.
- Write the pull request description the same way. A squash merge uses the pull request description as the commit body.
